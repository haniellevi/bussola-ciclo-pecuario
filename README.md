# Bússola do Ciclo Pecuário

Ferramenta gratuita de leitura do ciclo pecuário de corte no Brasil: fase atual, previsão semanal de preços (boi gordo e bezerro) com faixa de incerteza, e veredito de compra por perfil (Cria, Recria/Engorda, Iniciante).

**Não é recomendação de investimento.** É simulação estatística sobre dados públicos; o acerto histórico do modelo é publicado junto com cada previsão.

## Processo semanal

1. Coletar dados reais (Cepea, B3, Banco Central, IBGE, ComexStat, clima, notícias)
2. Conferir (data e fonte em cada número; valores fora do padrão vão para revisão)
3. Calcular fase do ciclo, relação de troca e previsões (4, 13 e 52 semanas)
4. Registrar a previsão (imutável)
5. Comparar com o realizado
6. Ajustar pesos, com registro do motivo
7. Publicar
